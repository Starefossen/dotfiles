# Global instructions

`~/AGENTS.md` is authoritative for git policy, guard rails, and everything else.
Read it. This file exists because Claude Code looks here, and repeats the one
rule that is easiest to break by reflex.

## Never add attribution trailers

Do NOT append any of these to a commit message or a pull-request body:

- `Co-Authored-By: Claude ...` — or any other AI/agent co-author trailer
- `Claude-Session:` or any similar session/run link
- `Generated with [Claude Code]` — or any equivalent tool footer

Write the message the change deserves and stop there.
